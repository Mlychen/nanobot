class MessageBus:
    def __init__(self):
        self.inbound: asyncio.Queue[InboundMessage]
        self.outbound: asyncio.Queue[OutboundMessage]

    async def publish_inbound(msg: InboundMessage) -> None
    async def consume_inbound() -> InboundMessage
    async def publish_outbound(msg: OutboundMessage) -> None
    async def consume_outbound() -> OutboundMessage

📋 AgentLoop Core Logic
▼

Core agent loop showing LLM interaction and tool execution flow

class AgentLoop:
    async def _run_agent_loop(messages, on_progress):
        while iteration < max_iterations:
            response = await provider.chat(messages, tools)

            if response.has_tool_calls:
                for tool_call in response.tool_calls:
                    result = await tools.execute(tool_call.name, args)
                    messages = add_tool_result(messages, result)
            else:
                break  # Final response

        return final_content, tools_used, messages

📋 Adding a New Provider
▼

Simple two-step process to add new LLM providers

Adding a new provider requires only 2 steps:

  1. Add ProviderSpec to PROVIDERS tuple in providers/registry.py
  2. Add field to ProvidersConfig in config/schema.py

Done. Env vars, prefixing, config matching, status display all derive from here.

Data Flow - Message Lifecycle

Interactive animation showing how a message flows through the system

SOURCE 👤 User Input
LAYER 1 📡 Channel receives message
LAYER 2 📨 InboundMessage → Bus
LAYER 3 🧠 AgentLoop processes
LAYER 4 🔧 Tool execution (if needed)
EXTERNAL ⚡ LLM Provider
LAYER 2 📤 OutboundMessage → Bus
DESTINATION 👤 Response to User

Step by Step Breakdown

1

👤 User Input

User sends a message through one of the supported channels (Telegram, Discord, Slack, etc.)

2

📡 Channel Reception

The channel's start() method receives the message and calls _handle_message() which validates the sender against the allowlist.

3

📨 InboundMessage Created

An InboundMessage dataclass is created with channel, sender_id, chat_id, content, and metadata. It's published to the MessageBus inbound queue.

4

🧠 AgentLoop Processing

AgentLoop.run() consumes the inbound message. _process_message() retrieves the session, builds context with conversation history via ContextBuilder.

5

🔄 Agent Iteration Loop

_run_agent_loop() iterates: calls LLM → parses tool calls → executes tools via ToolRegistry → adds results to messages. Continues until LLM returns final response.

6

🔧 Tool Execution (Optional)

If the LLM requests tool calls, ToolRegistry.execute() runs the appropriate tool (file operations, web search, shell commands, etc.) and returns results.

7

⚡ LLM Provider Call

The configured LLM provider (Anthropic, OpenAI, etc.) receives the prompt and returns a completion. Provider selection is handled by ProviderRegistry.

8

📤 OutboundMessage Created

The final response is wrapped in an OutboundMessage and published to the MessageBus outbound queue.

9

📬 Response Delivery

The channel's send() method delivers the response back to the user through the original chat platform.

🏛️ Inheritance Pattern
▼

All channels inherit from BaseChannel, ensuring consistent interface

All channels inherit from BaseChannel, ensuring consistent interface:

from nanobot.channels.base import BaseChannel

class TelegramChannel(BaseChannel):
    name = "telegram"

    async def start(self) -> None:
        # Connect to Telegram Bot API
        while self._running:
            msg = await self._poll_updates()
            await self._handle_message(...)

    async def send(self, msg: OutboundMessage):
        await self.bot.send_message(...)

    async def stop(self):
        self._running = False

def find_by_model(model: str) -> ProviderSpec | None:
    for spec in PROVIDERS:
        if any(kw in model for kw in spec.keywords):
            return spec
    return None
📨 Message Bus Pattern
▼

AsyncIO queues for decoupled communication

AsyncIO queues for decoupled communication:

class MessageBus:
    def __init__(self):
        self.inbound = asyncio.Queue[InboundMessage]()
        self.outbound = asyncio.Queue[OutboundMessage]()

    async def publish_inbound(self, msg):
        await self.inbound.put(msg)

    async def consume_inbound(self):
        return await self.inbound.get()

    # Channels publish, AgentLoop consumes
    # Full decoupling - no direct references
